# How They Blew Up

中文版：[README.zh.md](README.zh.md)

Data teardowns of how creators went from zero to a breakout: every post charted, the turning point found, and what you can copy.

This repo holds the free part of each case. The full teardowns (timeline, plays, lessons, money and brands) are at [blewup.co](https://blewup.co/?utm_source=github&utm_medium=repo).

Each case file is plain Markdown, written to be read by people and by AI agents.
